# D设计实施缺口

以下均待实现和运行验证。

- I01 技术及环境选型：数据库、运行时、框架版本、部署服务与费用；验证组合键、NULL唯一、条件更新和隔离能力。 完成证据：选型记录及合成环境能力试验
- I02 数据库与迁移：按116表候选形成DDL/迁移；未知旧值不猜补，非空集合及范围规则仍须领域校验。 完成证据：迁移预演、约束反例、完整性报告
- I03 关键事务与并发：实现根/明细/原版/历史/成功键共同提交；库存与季度新增来源谓词保护。 完成证据：独立连接屏障、故障注入、前后状态证据
- I04 当前权限及秘密：当前本人功能、诊所、对象、字段、明细/导出分别鉴权；角色变更同步有效许可。 完成证据：越权请求/响应/状态与凭据隔离证据
- I05 受控文件：文件备妥与数据库归档分阶段、不可变摘要、受控读取、错患者旧影像仅历史追查。 完成证据：中断/篡改/撤权/缺文件测试
- I06 表示层实现：实现37主要入口并补岗位变体和扩展；版本冲突、结果不明、旧响应、键盘窄屏操作。 完成证据：真实浏览器及键盘测试，不以原型截图代替
- I07 核算与查询：固定来源和口径的金额核对、整批结果、首次全范围时刻；查询原版及不同统计分母。 完成证据：固定数据集10次重算及明细守恒证据
- I08 备份与隔离恢复：同点DB/文件/密钥/成功键恢复；核对真实收款交付及现行授权缺口。 完成证据：实际RPO/RTO、缺口清单与批准记录
- I09 远程课程演示：获授权后创建HTTPS合成环境、最小账号、监测与访问说明，执行质量测试。 完成证据：可远程访问版本及Q01-Q05结果
- I10 真实机构运行评估：真实患者数据、保存/删除期限、法律医疗安全、运维责任及故障业务凭据另审。 完成证据：课程演示不能替代真实生产验收
