# 全系统ERD引用与导航

当前ERD对应完整数据模型166，结构沿D159，共116表866列、321项单列外键及29项组合外键。

- 原图为单页矢量PDF及SVG，包含全部字段。与教师选编中仅含键列的总图不同。
- 111项单列关系绘线，210项公共或次要引用按字段目标名列出；无长连线不表示没有外键。
- 350个内部导航跳转到对应表卡。合并阅读版中的跳转位于第275页；独立ERD跳转仍在自身单页内。
- 组合引用的源／目标字段顺序及候选键约束见[完整数据字典](data-dictionary.md)，不能只凭单列箭头推断复合关系。

优先打开[总图](../diagrams/ADC-ERD.pdf)放大，再对照字典与D设计。总览PNG仅便于导航，不替代原尺寸图纸。
