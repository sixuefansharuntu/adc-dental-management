# ADC牙科连锁运营管理系统

系统分析与设计课程项目，以日常就诊、诊疗收费和物资业务形成的可追溯资料为基础，支持总部核对并确认牙医季度业绩，覆盖患者预约与取消、排班接诊、临床影像、义齿加工、诊后随访、经营查询及访问管理。

## 完整设计范围

32个系统用例、83个分析类（9边界、32控制、42实体）、408项分析操作、98项领域关联、52张分析序列图和10组状态机。数据层116表866列，321项单列引用和29项组合引用。开发依据保留全部操作与字段，展示选编不会反向删除功能。

患者预约由系统检查后直接生效，符合规则可自助改约或取消；前台登记真实到院、接诊开始、结束和离开，医生确认临床内容。UC11参考价维护与UC12医护开单分开；UC25由诊所管理人员提交，财务核算、总部复核。收款与商品实际交付分开，实际交付才作用库存。季度核算保留原范围、来源版本和首次完成时刻。
