# 实地调研记录

本目录收录课程项目实地调研的5张现场照片，展示赛德雅口腔的门店、前台交流场景及诊疗环境，为理解口腔诊所的实际工作场景提供补充材料。

实地调研地点与课程案例中的ADC牙科连锁组织不同。照片用于记录现场场景，不将该门店直接等同于ADC，也不单凭照片认定岗位职责、软件功能或季度核算规则；具体需求及设计见[A至C正文](../docs/ADC-ABC.pdf)。
